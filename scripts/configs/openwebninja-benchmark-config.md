# OpenWeb Ninja Trustpilot Benchmark Configuration

## Tool

OpenWeb Ninja Trustpilot Company and Reviews Data API

## Benchmark Objective

Evaluate OpenWeb Ninja using the requirements defined in:

- `docs/testing-criteria.md`
- `docs/structure-template.md`

The benchmark must measure:

- reliability
- data quality
- cost
- speed
- scalability
- developer experience
- input flexibility

No result, field, cost, or capability may be invented.
